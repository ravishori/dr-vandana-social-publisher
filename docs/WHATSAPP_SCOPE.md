# WhatsApp Scope

WhatsApp Business messaging, WhatsApp Channels, Broadcast-style outreach and ordinary Groups are different product/API surfaces.

The prototype therefore does not pretend to support generic WhatsApp Group/Channel automation.

The adapter currently returns `not_configured`.

Implement only an officially supported Meta API capability after verifying:
- account eligibility
- exact product surface
- current API
- permissions
- consent/template requirements
- destination support

Do not use unofficial WhatsApp Web automation.
