# Telegram Setup

1. Open Telegram and use `@BotFather`.
2. Create a bot and copy the token.
3. Add the bot to the target Channel.
4. Give it only the permissions required for posting.
5. For a public channel, configure `TELEGRAM_CHANNEL_ID=@channel_username`.
6. Add the bot to the target Group/Supergroup.
7. Configure the numeric group chat ID.
8. Test in `PUBLISH_MODE=mock`.
9. Switch to `PUBLISH_MODE=live` only when ready.
10. Test with synthetic content first.

Do not use patient/client information during provider testing.
